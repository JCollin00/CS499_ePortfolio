ARTIFACT OVERVIEW

ABCU Course Planner Application

Originally developed in C++ for CS 300, this application parses course data from CSV files and displays sorted course catalogs for academic advisors.

The Optimization: Replaced the original Binary Search Tree (BST) with a self-balancing AVL Tree to eliminate worst-case performance risks and guarantee logarithmic execution times.

Key Technical Enhancements

While the original BST performed well with unsorted input, loading sorted course data caused the tree to degrade into a linear structure, increasing search and insertion times from O(log n) to O(n).

  • Guaranteed O(log n) Complexity: Enforced strict tree balancing after every insertion to prevent performance degradation.
  • Automated Balancing Rotations: Implemented all four AVL rotation algorithms:
    • LL & RR Rotations: Single rotations for left-heavy or right-heavy subtrees.
    • LR & RL Rotations: Double rotations for complex inner-child imbalances.
  • Preserved In-Order Traversal: Retained O(n) sorted output capabilities without needing separate sorting algorithms, balancing search efficiency with ordered display.

Program Outcome Coverage

This enhancement directly addresses the Computer Science outcome of designing and evaluating computing solutions using algorithmic principles. Key skills demonstrated include:

  • Analyzing runtime efficiency and identifying performance bottlenecks in legacy code.
  • Implementing recursive tree algorithms and balance factor maintenance in C++.
  • Evaluating algorithmic trade-offs (e.g., comparing AVL Trees vs. Hash Tables for sorted data display).

Reflection

Upgrading this project highlighted the difference between software that simply works and software engineered for scalability. Balancing the tree while keeping CSV parsing and search features fully intact presented a strong engineering challenge, reinforcing the importance of algorithmic analysis in modern software development.
